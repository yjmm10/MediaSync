# 博客园：启用数学公式支持

## 现象

同步到博客园后，公式以 `$...$` / `$$...$$` 原文显示，页面上不渲染。

## 原因

博客园需在后台手动开启数学公式支持，并选择渲染引擎（MathJax 或 KaTeX）。未开启时，Markdown 中的 TeX 语法不会被渲染。

## 操作步骤

1. 进入博客后台 → **【选项】**（注意：部分旧版界面在 **【设置】**）。
2. 勾选「启用数学公式支持」后，下方通常会让你选择渲染引擎，请确保勾选了 **MathJax** 或 **KaTeX**。
3. 拉到页面最底部，点击 **【保存】**。

后台入口：https://i.cnblogs.com/

## 补充

适配器以 Markdown 同步 TeX 语法；开启后由博客园前端渲染。编辑器可使用 Markdown 工具栏的 TEX 按钮插入公式。

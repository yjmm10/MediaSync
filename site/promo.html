同步派 MediaSync：一键把文章同步到 29+ 平台

开源免费的浏览器扩展。用你已有的登录态，把一篇文章同步到知乎、掘金、CSDN、头条、简书等平台——默认保存为草稿，由你确认后再发布。

第一次用扩展？安装后打开本页，在侧栏点「检测当前页」，即可把这篇宣传文同步出去，顺带验证各平台对 Markdown 的支持情况。

为什么是同步派

自媒体分发最烦的是同一篇内容复制粘贴 N 遍。同步派不模拟登录、不经过第三方服务器：直接使用浏览器里已有的 Cookie，调用各平台官方 Web API，与你在网页编辑器里手动发布等价。

核心原则只有四条：使用你自己的登录态、调用平台官方接口、数据不离开你的设备、以及草稿优先。

你可以怎么用

  • 从微信公众号、网页文章或本地 Markdown 导入正文
  • 一次勾选多个平台批量同步
  • 图片自动上传到目标平台图床
  • 配合 CLI / MCP，在终端或 Claude 里发起同步

多级列表示例

  • 安装扩展并登录目标平台
    • Chrome / Edge / Firefox 均可
    • 商店安装或手动加载 Release 包
  • 打开要同步的文章页（比如本页）
  • 侧栏检测 → 选择平台 → 开始同步

产品能力一览

下表用 Markdown 表格 概括同步派的定位（同步后可对照各平台表格渲染效果）：

能力说明状态
多平台同步知乎、掘金、CSDN、简书等 29+可用
本地 Markdown文件夹导入 md + 本地图片可用

「不是爬虫，不模拟登录，不经过任何中间服务器。」——这是同步派与常见「云同步」工具最大的区别。

Markdown 语法自检（同步后对照）

以下片段覆盖常用语法：加粗、斜体、行内代码如 mediasync sync，以及代码块、Mermaid、列表与分隔线。把本页同步到不同平台，就能直观看到「完整 / 部分 / 弱」的差异。

普通代码块

# 安装 CLI 后同步一篇本地文章
npm install -g @mediasync/cli
export MEDIASYNC_TOKEN="你的token"
mediasync sync article.md -p zhihu,juejin,csdn

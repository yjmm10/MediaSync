项目介绍

不是爬虫，不模拟登录，不经过任何第三方服务器

同步派是一款开源免费的 Chrome 浏览器扩展，工作方式与浏览器本身一致——直接使用你在浏览器中已有的登录态，调用各平台官方接口完成发布。你的 Cookie、文章内容、账号信息不经过任何中间服务器，源代码完全开源可审计。

1

使用你自己的登录态

你在浏览器里正常登录各平台，扩展直接使用已有的 Cookie，无需额外授权，无需输入密码。

2

调用平台官方接口

发布时调用的是各平台 Web 编辑器使用的同一套官方 API，与你手动在网页发布完全等价。

3

数据不离开你的设备

所有请求直接从你的浏览器发往各平台，没有中间服务器，没有数据上传，安全可审计。

4

草稿优先

默认将文章同步为草稿，发布前由你人工确认，扩展不会自动发布任何内容。少数平台例外 →

核心功能

🚀

一键批量发布

将文章同步到知乎、掘金、头条、CSDN、微博、小红书、阿里云开发者社区等 35+ 自媒体平台，一次编写多处发布。

📝

网页转 Markdown

任意网页智能提取正文，自动过滤广告，图片本地化，打包为 Markdown + 图片 ZIP 压缩包。

📂

本地 Markdown 导入

选择含 .md 与本地图片的文件夹，预览后一键同步多平台，自动处理相对路径图片。

📚

历史按文档归档

同一文档多次同步合并为一条记录，支持追加更多平台，封面用正文首图兜底。

🏠

自建站支持

WordPress、Typecho、博客园（MetaWeblog API），自建博客也能一键同步引流。

🖼️

图片自动上传

自动转存文章图片到目标平台 CDN，无需手动处理图片链接，保留排版样式。

🤖

AI 集成

支持 Anthropic MCP / Claude Code Skill，用自然语言指挥 AI 完成提取与一键发布。

🔒

本地与开源

数据本地存储，账号信息不上传，代码完全开源透明，可自行审计与定制。

平台限制

下列为适配器内已实现的字数 / 发布策略说明（Markdown 细则见上方语法矩阵）：

平台限制说明
微信公众号 标题≤64 字、摘要≤120 字；正文插入视频≤3 个（超限由平台接口报错）。
小红书 长文草稿：标题≤64 字、正文≤约 1 万字（超限自动截断）。需已登录创作者中心；同步后到草稿箱 → 长文查看。已知问题：图片上传/转存尚不稳定，将在下版本修复；本版本建议纯文本或同步后手工补图。
虎扑 直接发布（无草稿接口）。同步后发帖到步行街（即时可见）；标题需 4–40 字。
美篇 直接发布（无独立草稿箱，同步后公开）。需先打开 美篇编辑器 并登录。已知问题：图片上传/转存尚不稳定。
企鹅号 标题需 5–64 字；仅保存草稿，不调用发布接口。
阿里云开发者社区 草稿同步。支持外链与本地图转存（失败则回退纯文字）。不传摘要（请在草稿箱手工补）。Mermaid 保留为普通代码块（平台不渲染图）。
百度开发者中心 草稿同步。支持外链与本地图转存。不支持 Mermaid（原样保留代码块）。公式行内/块级均使用 $$...$$。
V2EX 直接发布到节点 algorithm。暂不支持外链图床转存、本地图、公式、Mermaid。
千帆 / 腾讯云 / 火山 / 魔搭 草稿同步。千帆不支持外链中转与本地图；腾讯云/火山/魔搭支持外链中转、不支持本地图（魔搭另需勋章，Mermaid/公式降级）。

其余平台为草稿同步，适配器未做额外字数截断；同步完成后请在各平台后台确认再正式公开。

Chrome 网上应用店链接后续补充。当前可从 Release 下载 mediasync-*-chrome.zip（与 edge 包同内容）解压加载；另提供 .crx（若有签名）。

商店链接待补充

⌨️ CLI 命令行工具

无需配置 MCP，安装即用。需先在扩展设置中启用「MCP 连接」获取 Token。

npm install -g @mediasync/cli
export MEDIASYNC_TOKEN="你的token"
mediasync sync article.md -p zhihu,juejin

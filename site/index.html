项目介绍

不是爬虫，不模拟登录，不经过任何第三方服务器

同步派是一款开源免费的 Chrome 浏览器扩展，工作方式与浏览器本身一致——直接使用你在浏览器中已有的登录态，调用各平台官方接口完成发布。你的 Cookie、文章内容、账号信息不经过任何中间服务器，源代码完全开源可审计。

1

使用你自己的登录态

你在浏览器里正常登录各平台，扩展直接使用已有的 Cookie，无需额外授权，无需输入密码。

2

调用平台官方接口

发布时调用的是各平台 Web 编辑器使用的同一套官方 API，与你手动在网页发布完全等价。

3

数据不离开你的设备

所有请求直接从你的浏览器发往各平台，没有中间服务器，没有数据上传，安全可审计。

4

草稿优先

默认将文章同步为草稿，发布前由你人工确认，扩展不会自动发布任何内容。

核心功能

🚀

一键批量发布

将文章同步到知乎、掘金、头条、CSDN、微博、小红书等 29+ 自媒体平台，一次编写多处发布。

📝

网页转 Markdown

任意网页智能提取正文，自动过滤广告，图片本地化，打包为 Markdown + 图片 ZIP 压缩包。

📂

本地 Markdown 导入

选择含 .md 与本地图片的文件夹，预览后一键同步多平台，自动处理相对路径图片。

📚

历史按文档归档

同一文档多次同步合并为一条记录，支持追加更多平台，封面用正文首图兜底。

🏠

自建站支持

WordPress、Typecho、博客园（MetaWeblog API），自建博客也能一键同步引流。

🖼️

图片自动上传

自动转存文章图片到目标平台 CDN，无需手动处理图片链接，保留排版样式。

🤖

AI 集成

支持 Anthropic MCP / Claude Code Skill，用自然语言指挥 AI 完成提取与一键发布。

🔒

本地与开源

数据本地存储，账号信息不上传，代码完全开源透明，可自行审计与定制。

开始使用

两种方式，按需选择

🖥️ Chrome 扩展（推荐）

从 Chrome 网上应用店安装，支持 Chrome / Edge / 360 / QQ 等 Chromium 内核浏览器，自动更新。

安装扩展

⌨️ CLI 命令行工具

无需配置 MCP，安装即用。需先在扩展设置中启用「MCP 连接」获取 Token。

npm install -g @mediasync/cli
export MEDIASYNC_TOKEN="你的token"
mediasync sync article.md -p zhihu,juejin
